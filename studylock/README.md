StudyLock is a Flutter study companion for focused study sessions, document-based AI preparation, and Android app lockdown.

## Repository scope

This repository contains:

- The Flutter application in `lib/`
- The Android accessibility implementation in `android/app/src/main/`
- Platform projects generated by Flutter

The AI HTTP backend is deployed separately at `https://study-lock-xakx.onrender.com`; its server source is not included in this repository. See the [backend README](docs/backend/README.md) for the observed API contract.

## Quick start

### Requirements

- Flutter SDK compatible with Dart `^3.13.1`
- Android SDK and Java 17 for Android builds
- An Android device or emulator for accessibility-service testing

### Run

```bash
flutter pub get
flutter run
```

### Validate

```bash
flutter analyze
flutter build apk --debug
```

## Android lockdown setup

1. Install the debug APK on an Android device.
2. Open **Focus Mode**.
3. Select **Enable Accessibility Service**.
4. Enable **StudyLock app blocker** in Android Accessibility settings.
5. Start a focus session.

During a session, StudyLock can leave the foreground to the launcher, while the native accessibility service redirects attempts to open blocked applications back to StudyLock. Phone, the default SMS application, the launcher, Android System UI, and Settings remain available.

## Current limitations

- The accessibility service is Android-specific.
- Focus state is held in memory and is not restored after process termination.
- The AI service URL is currently configured in source code.
- The external backend implementation and deployment configuration are not part of this repository.
